# sap-family-tree
Tracks an atypical family tree, like those in mythology, where relationships aren't as straightforward. 

# Technology
Uses Typescript, Neo4j, React.js, and Cytoscape.js. Data is tracked in a multigraph, where two nodes can have multiple edges (relationships) together.


# How to set up the Project (runs locally)

Step 1: install `node (25.0.0)`, `npm (11.6.3)`, and VS Code.
Step 2: install typescript & node: `npm install --save-dev typescript @types/node tsx`
Step 3: install express: `npm install express` and `npm install --save-dev @types/express`

# How to Start the Project

(in terminal, under server) `npm run dev`
